## Introduction

Septembre 2025, un samedi après-midi où j’ai un peu de répit avant la fin de la sieste des gnomes, une idée malheureuse germe dans mon esprit : et si je me mettais bien pour le télétravail. Si je soignais un peu mon "setup", vu le temps que je passe devant un écran et dans ce bureau (2 jours/semaine). Et si je soignais un peu cette gêne que j’ai depuis si longtemps dans l’avant-bras/poignet gauche et au niveau des épaules.

Je pensais juste réorganiser mon espace de travail. La vérité : des heures au carré passées à explorer __l’ergonomie__ (je n’ose pas calculer, mais ça doit représenter plusieurs centaines d’heures).

Dans ce billet, je détaille ce parcours – fait dans le mauvais ordre – dans l’espoir qu’il puisse faire gagner du temps à d’autres. Et aussi pour apporter une note dissonante à tout ce qu’on peut lire sur l’ergonomie des claviers, note que l’on trouve sans doute peu car ceux qui sont arrivés à ma conclusion sont juste passé à autre chose.

## Mon parcours

Voici l’ordre chronologique de toutes mes bêtises pour améliorer mon setup.

### Septembre 2025 : état des lieux

Ça fait quelque temps que je suis passé à un des écrans orienté en portrait. La raison n’est pas d’afficher du texte sur une grande hauteur. C’est juste que 2 écrans en mode paysage m’obligent à trop tourner la tête. Cette configuration optimise mon champ de vision et mes cervicales. J’utilise le mode portrait pour empiler 2 fenêtres  peu consultées. Je passe le plus clair de mon temps sur l’écran principal. Si une activité m’occupe plus de quelques minutes d’affilée, elle bascule sur l’écran principal.
```
			‑--------------------- --------------
			|                    | |            |
			|       écran        | |            |
			|     principal      | |   écran    |
			|                    | |            |
			‑--------------------- |  ternaire  |
			  ‑-----------------   |            |
			  |                |   |            |
			  |    portable    |   |            |
			  |écran secondaire|   |            |
			  |                |   |            |
			  ‑-----------------   --------------
```

🔴 Le problème de cette organisation est qu’on ne peut pas y mettre un clavier. Je ne sais pas trop pourquoi, mais j’ai bien envie d’en mettre un… Je m’approche du terrier…

### Octobre 2025 : Installation support écran

Je voulais retirer les livres sous mes écrans et les remplacer par un support articulé. Ça coûte pas cher et ça libère de l’espace. Ça me permettra de placer mon superbe « Microsoft Comfort Curve 2000 » 15 ans d’age qui moisit dans mes cartons. 

Mon plan initial :
```
  ‑----------------- ‑--------------------- --------------
  |                | |                    | |            |
  |      écran     | |       écran        | |            |
  |    portable    | |     principal      | |   écran    |
  |  (secondaire)  | |                    | |            |
  ‑----------------- ‑--------------------- |  ternaire  |
			                                   |            |
			                                   |            |
			                                   |            |
			                                   |            |
			            ______________________ |            |
			            |       clavier      | --------------
```

La réalité :
- mon écran de portable est loin, je peine à lire
- je passe trop de temps la tête tournée
Là où je me suis planté : j’ai voulu mettre le portable en hauteur pour libérer totalement la place pour un clavier. Résultat : le portable qui était en face de moi est passé à gauche de mon écran principal et je passais beaucoup de temps la tête tournée.

>>
Mon installation finale :
```
			‑--------------------- --------------
			|                    | |            |
			|       écran        | |            |
			|     principal      | |   écran    |
			|                    | |            |
			‑--------------------- |  ternaire  |
			  ‑-----------------   |            |
			  |                |   |            |
			  |      écran     |   |            |
			  |    portable    |   |            |
			  |  (secondaire)  |   |            |
			  ‑-----------------   --------------

```

Ma recommendation :
- avant d’acheter cet écran 72 pouces, pose-toi la question du recul. Il y a des règles de distance entre les yeux et l’écran selon la taille de l’écran. En bref, si ton écran est trop grand, tu vas tourner devoir tourner la tête pour le regarder d’un bord à l’autre.
- 2 « petits » écrans coûtent moins chers qu’un énorme écran. Et en plus, les fenêtres sont faciles à gérer (sur un grand écran, tu vas rarement maximiser une fenêtre).
- Si tu alignes 3 écrans à la même hauteur, tu vas beaucoup tourner la tête. C’est plus confortable de la baisser que de la tourner.
- Dans tous les cas, travaille le plus possible sur un seul écran, bien face à toi, à la bonne hauteur et que tu peux regarder en entier sans bouger la tête.
<<

### Installation d’un clavier externe

Ça y’est j’ai reçu mon support d’écran avec bras articulé. Je vais pouvoir ressortir ce bon vieux Microsoft Comfort Curve 2000 ! Que d’heures passées sur cette merveille d’ergonomie dans ma jeunesse fougeuse.

J’essaie 10 minutes, et là, aie, j’ai beau être matinal… C’est carrément pire que de taper sur un portable. C’est vrai que le clavier a vieilli et que je l’avais déjà démonté plusieurs fois pour le ressuciter. Et aussi, passer du toucher facile d’un portable à cette planche…je suis pas prêt. Et en plus, cet écran de portable à gauche en hauteur…maintenant j’ai mal aussi au cou!

Bon l’écran de portable en hauteur à gauche, c’est de la merde.



Avec cette installation, tu vas te demander où foutre ce clavier ? C’est tout con et des mois d’expérience montrent que ça marche : la cale !

Une boîte de lunette un peu oblique marche bien. Sinon, une cale en bois et un bout de scotch de bricolage sous le clavier pour pas que ça glisse, et voilà, ton clavier passe un peu en dessous et ton écran de portable ne s’est pas trop éloigné.


Je travaille depuis des années sur des ordis portables. La seule chose que j’ai jamais trouvé génante sur ces claviers et que un de mes bras prenait le chaud l’ordi moulinait (ce qui arrive beaucoup dans mon métier). Mais bon, je voulais voir si c’était mieux avec un bon vieux clavier d’antant. J’ai ressorti mon antique clavier Micro
